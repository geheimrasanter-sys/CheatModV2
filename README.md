# CheatMod V2 - Tekkit Lite

Ein verbesserter Forge CheatMod für Minecraft 1.6.4 (Tekkit Lite).

## Features

- **Fly (F)** - Flugmodus an/aus
- **Speed (V/C)** - Geschwindigkeit einstellbar
  - V = Speed erhöhen
  - C = Speed senken
  - Bereich: 0.5x bis 5.0x
- **XRay (X)** - Durchsichtigkeit der Blöcke an/aus

## Steuerung

| Taste | Funktion |
|-------|----------|
| **F** | Fly Toggle |
| **V** | Speed + |
| **C** | Speed - |
| **X** | XRay Toggle |

## Installation

1. JAR in `mods` Ordner von Tekkit Lite kopieren
2. Minecraft neustarten

## Build

```bash
git clone https://github.com/geheimrasanter-sys/CheatModV2.git
cd CheatModV2
./gradlew setupDecompWorkspace
./gradlew build
```

JAR: `build/libs/CheatMod-2.0.jar`
